## ✅ Per-Page Optimization Checklist (5.5h per page)

Before marking page complete, verify:

**Content & Structure (2h)**
- [ ] Meta title: 50–60 chars, keyword-focused
- [ ] Meta description: 150–160 chars
- [ ] H1: Single, clear, matches page intent
- [ ] H2s: 4–6 per page, keyword variants, logical flow
- [ ] Word count: 1,200–1,800 words
- [ ] Keyword mentions: Natural, 2–3 times main keyword

**Internal Links (0.5h)**
- [ ] 3+ contextual links to related pages
- [ ] Links to other pillars (e.g. /fine-dining → /catering)
- [ ] Links to relevant blog posts
- [ ] No broken links (test before commit)

**Multimedia (1h)**
- [ ] 5–8 images per page
- [ ] Explicit width/height attributes
- [ ] Semantic alt text (describes image, includes keyword when natural)
- [ ] Image optimization (compressed, lazy-loaded)

**Schema Markup (0.5h)**
- [ ] FAQPage OR Service schema (JSON-LD)
- [ ] Validates in Google Rich Results Test
- [ ] Relevant to page topic

**CTAs & Setup (0.75h)**
- [ ] "Book Now" button visible
- [ ] Contact form accessible
- [ ] WhatsApp link functional
- [ ] Mobile rendering tested (320, 768, 1024, 1440px)

**Build & Testing (0.5h)**
- [ ] `pnpm build` passes (zero errors)
- [ ] Zero TypeScript errors
- [ ] Page loads in <3s
- [ ] Mobile responsive (no overflow)
- [ ] All links valid (no 404s)

## 🚨 When to Escalate / Ask for Help

**STOP and escalate if:**

| Issue | Action | Escalate to |
|-------|--------|-------------|
| Build fails after content changes | Fix error, test locally, commit | Build lead |
| CWV drops >10% (e.g. LCP >2.8s) | Identify cause (images? JS?), optimize | Performance lead |
| Blog post not indexed after 10 days | Resubmit sitemap, check robots.txt | SEO lead |
| 404 errors from new internal links | Fix links before merge | QA lead |
| Page feels slower than expected | Profile with PageSpeed, optimize | Performance lead |
| Can't complete page in 5.5h | Document blockers, adjust estimate | Project lead |
| 10+ keywords drop position 3+ | Document, flag for competitor analysis | SEO lead |
