### Heading Structure (H1-H3)
**Status:** ⚠️ INCONSISTENT

**Issue [HIGH]:** H1 tags not consistently semantic.

**Evidence:**
```tsx
// Some pages use semantic H1:
<h1 className="text-3xl">Private Chef Bali</h1>

// Others use styled H2/H3 as visual H1:
<h2 className="text-4xl font-playfair">How It Works</h2>
```

**Impact:** 
- Search engines may struggle to identify primary page topic
- Accessibility tools rely on H1 for page structure
- Internal content hierarchy unclear

**Fix [HIGH]:**
1. Ensure every page has exactly ONE H1 tag
2. H1 should be the first major heading (hero title)
3. Use H2 for section headers, H3 for subsections
4. Never skip heading levels (H1 → H3)

**Files to audit:** All `src/pages/*.tsx`

## Internal Linking

**Status:** ⚠️ WEAK

**Issue [HIGH]:** Service pages mention "across Bali" and location names but don't link to location pages.

**Evidence:**
```tsx
// CateringMainPage.tsx line 298:
"We specialize in villa catering across Bali."
// Should link to /locations

// Multiple pages mention "Seminyak, Canggu, Ubud" without links
```

**Impact:**
- Lost link equity distribution
- Users can't navigate to relevant location pages
- Search engines can't discover page relationships

**Fix [HIGH]:**
1. Add contextual links from service pages → location pages
2. Add contextual links from location pages → service pages
3. Use descriptive anchor text ("private chef in Seminyak" not "click here")

**Target pattern:**
```tsx
We serve <Link to="/locations/seminyak">Seminyak</Link>, 
<Link to="/locations/canggu">Canggu</Link>, and 
<Link to="/locations/ubud">Ubud</Link> across Bali.
```
