## CALL SCRIPT (Follow Exactly)

### OPENING (30 seconds)
```
"Hi Alessandro, it's David. Quick call about the myCHEF website launch. 
We're going live on the 18th and need your final decision on a couple things. 
Got 5 minutes?"
```

**If YES → Continue to Main Questions**  
**If NO → "When's good to call back?" → Reschedule**

---

### MAIN QUESTIONS (Key Decision Points)

#### QUESTION 1: Menus Finalized? (1 min)
```
"First — are the three signature menus finalized? 
I need to know:
1. What are the exact three menus we're going with?
2. How many courses in each?
3. Any special dietary versions (vegan, gluten-free, etc)?
4. Are you 100% locked in or still tweaking?"
```

**Listen for**: 
- Menu names (record exactly)
- Course count
- Dietary variations
- Confidence level

**If hesitant**:
```
"When will they be locked? Do you need more time?"
```

**If locked**:
```
"Perfect. Moving to photography."
```

---

#### QUESTION 2: Photographer Booked? (1.5 min)
```
"Now the big one — is the photographer booked?
Details I need:
1. Have you selected a photographer? Name?
2. When is the shoot scheduled?
3. How many hours of shooting?
4. What's the budget?
5. When will you deliver the 30+ edited photos?"
```

**Listen for**:
- Photographer name/contact
- Specific dates locked
- Budget confirmed
- Delivery timeline

**If NOT booked**:
```
"We need this locked THIS WEEK. Can you find someone by [DATE]?
What's your biggest blocker — budget, availability, or something else?"
```

**If booked**:
```
"Excellent. When are the photos due?"
```

---

#### QUESTION 3: Can you deliver by 28 May? (1 min)
```
"So the hard deadline is 28 May for all 30+ photos 
edited and ready for the website.
Can you make that?"
```

**If YES**:
```
"Perfect. Document: photos ready 28 May."
```

**If NO**:
```
"What's the actual date? We need to adjust our launch plan if it's later."
```

---

#### QUESTION 4: Any Other Blockers? (1 min)
```
"Is there anything else that could get in the way? 
Budget, supplier issues, kitchen access, anything?"
```

**Listen for**: Any new constraints

**If blocker found**:
```
"OK, what do you need from me to solve that?"
```

---
