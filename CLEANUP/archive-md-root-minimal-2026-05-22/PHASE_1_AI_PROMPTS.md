## Generation Instructions

### Midjourney Workflow

1. **Batch Generation:**
   ```
   /imagine [Prompt 1.1]
   /imagine [Prompt 1.2]
   /imagine [Prompt 1.3]
   ...
   ```

2. **Upscaling:**
   - For each output, upscale U1, U2, U3, U4 variants
   - Select the best 2-3 per prompt
   - Target: 50-80 final images

3. **Style Consistency:**
   - All images should feel cohesive (same resort, same brand)
   - Use consistent color grading across batches
   - If consistency drifts, use same seed for related images

4. **Resolution:**
   - Default Midjourney output is 1024x1024px
   - Upscale to 2048x2048px minimum for production use
   - Download hi-res PNG versions

### DALL-E 3 Workflow

1. Copy prompt into ChatGPT with DALL-E 3 enabled
2. Generate 2-3 variations per prompt
3. Edit if needed (unlikely with detailed prompts above)
4. Download full-resolution PNG

### Organization

After generation:
1. Create folder structure in Figma:
   ```
   myCHEF Brand Assets
   ├── Chef Portraits (8-10 images)
   ├── Food Photography (10-12 images)
   ├── Villa & Service (12-15 images)
   ├── Lifestyle & Experience (8-10 images)
   └── Architectural (6-8 images)
   ```

2. Add each image as a Figma asset component
3. Tag with: `brand`, `hero`, `category`, `ratio-16:9-or-1:1`
