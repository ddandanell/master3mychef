This project is deployed on Vercel and must be treated as production-sensitive.

Main rules:
- Never push directly to main.
- Use feature branches.
- Use pull requests.
- Build must pass before merge.
- Vercel Preview must pass before production.
- No direct production changes.
- No destructive changes without approval.
- No broad refactors unless requested.
- Prefer small patches.
- Protect SEO, routes, forms, APIs, metadata, sitemap, robots.txt, and redirects.
- Explain risk before changing code.
