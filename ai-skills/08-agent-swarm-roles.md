Swarm role rules:

Agent 1: Codebase Mapper
Find relevant files and system structure.

Agent 2: Build Debugger
Find build, TypeScript, dependency, import, and runtime risks.

Agent 3: Vercel Reviewer
Check Vercel deployment, build command, env vars, preview risk, and config risk.

Agent 4: SEO and Route Protector
Check routes, metadata, sitemap, redirects, internal links, and CTAs.

Agent 5: Final Gatekeeper
Decide PASS, BLOCKED, or NEEDS HUMAN REVIEW.

No agent may approve its own work.
Final Gatekeeper must be stricter than the coding agent.
