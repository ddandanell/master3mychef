6. WHAT STILL NEEDS MANUAL SETUP IN GA4 DASHBOARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  All events fire automatically after the CSP fix deploys. But GA4
  does not automatically treat events as "conversions" — you must
  mark them manually in the dashboard.

  STEP 1 — Mark these events as conversions:
    Go to: https://analytics.google.com/analytics/web/#/p[PROPERTY_ID]/admin/conversions
    (replace [PROPERTY_ID] with your GA4 property ID)

    Mark as conversion:
      ✓ generate_lead    (WhatsApp + Phone clicks — the primary KPI)
      ✓ quote_submitted  (quote funnel final CTA click)

    Optional / engagement:
      ✓ form_complete    (if you add this to quote funnel later)

  STEP 2 — Create custom dimensions for richer reports:
    Go to: Admin > Custom definitions > Custom dimensions
    Add:
      Dimension name: source          Scope: Event   Parameter: source
      Dimension name: method          Scope: Event   Parameter: method
      Dimension name: service_type    Scope: Event   Parameter: service_type
      Dimension name: page_context    Scope: Event   Parameter: page_context
      Dimension name: scroll_depth    Scope: Event   Parameter: scroll_depth
      Dimension name: time_on_page    Scope: Event   Parameter: time_on_page

  STEP 3 — Create an Exploration report to see WhatsApp sources:
    Go to: Explore > Blank exploration
    Dimensions: event_name, source, method
    Metrics: event_count
    Filter: event_name = generate_lead
    This shows which CTAs drive the most WhatsApp clicks.

  STEP 4 — Enable scroll_depth and time_on_page hooks (optional):
    The hooks useScrollDepth and useTimeOnPage exist in:
      src/hooks/useScrollDepth.ts
      src/hooks/useTimeOnPage.ts
    They are fully built but not called anywhere. To activate, add
    these to any high-traffic page component:
      import { useScrollDepth } from '@/hooks/useScrollDepth'
      import { useTimeOnPage } from '@/hooks/useTimeOnPage'
      // inside component:
      useScrollDepth('fine-dining')
      useTimeOnPage('fine-diving')
    Recommended pages to instrument first:
      - FineDiningPage (highest value page)
      - PricingGuide (high purchase intent)
      - QuoteFunnel (step-by-step engagement data)

  STEP 5 — Verify data is flowing (do this after Vercel deploys):
    Go to: https://analytics.google.com/analytics/web/#/p[PROPERTY_ID]/realtime
    Open mychef.id in another tab, click a WhatsApp button.
    You should see a generate_lead event appear in realtime within 5s.
    If you see it: tracking is working.
    If not: check browser console for CSP errors (should be fixed now).
