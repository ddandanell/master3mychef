# golden_examples

**Hand-picked** reference conversations — the gold standard for how Peter should handle a
situation. Unlike `good_conversations/` (auto-collected), these are human-curated and stable,
used as the canonical few-shot set and as regression checks (Peter should never get worse
than these on the same persona + scenario).

Add a short header to each file explaining *why* it's golden.
Keep this set small and high-quality (e.g. 10–20 examples), one per key scenario:
price objection · chef-direct request · last-minute · big group · dietary · staffing enquiry.
