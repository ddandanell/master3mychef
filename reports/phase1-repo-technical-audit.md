## 1. Summary

The MyChef website (`mychef.id`) is a **Vite + React 19 SPA** with a sophisticated build pipeline that includes prebuild validation, automated sitemap generation, postbuild meta injection, and Playwright-based prerendering. The codebase demonstrates **strong SEO discipline** with comprehensive schema markup, a large redirect map, AI-crawler-friendly robots.txt, and code-splitting across 180+ routes.

**Overall Grade: B+** — Solid technical foundation with a few high-impact issues that need immediate attention.

**Critical Issues (2):**
1. Duplicate redirect entries in `vercel.json` (risk of deployment warnings / undefined behavior)
2. Prerender route list is ~183 routes while sitemap contains 223 URLs — 40 pages not prerendered

**High-Priority Issues (3):**
3. No responsive image support (`srcset` / WebP fallbacks) in `OptimizedImage`
4. Some generated images exceed 700KB (largest: 740KB)
5. No dedicated a11y linter in CI; axe tests exist but are not enforced on build

## 7. Image Optimization

### `OptimizedImage` Component
```tsx
export default function OptimizedImage({ src, width, height, loading, decoding, ...props }) {
  const inferred = typeof src === 'string' ? getImageDimensions(src) : undefined
  return (
    <img
      {...props}
      src={src}
      width={width ?? inferred?.width}
      height={height ?? inferred?.height}
      loading={loading ?? 'lazy'}
      decoding={decoding ?? 'async'}
    />
  )
}
```

**Strengths:**
- ✅ Default `loading="lazy"` on all images
- ✅ Default `decoding="async"`
- ✅ Inferred dimensions from `getImageDimensions()` to prevent CLS

**Weaknesses:**
- ❌ **No `srcset` / responsive images** — serves same image to all viewports
- ❌ **No WebP/AVIF fallbacks** — all images are `.webp` already, but no `<picture>` element for older browsers
- ❌ **No `fetchpriority` prop exposure** — cannot mark LCP images as high priority (except homepage hero which is preloaded in `index.html`)
- ❌ **No blur-up / placeholder** — images pop in without smooth transition
