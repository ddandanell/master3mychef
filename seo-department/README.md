# myCHEF.id — AI SEO Department

A complete SEO department: 24 specialist roles, operating rules, live working files and reusable templates.

## Start here
1. **`00-SEO-MASTER-SYSTEM.md`** — how the department operates, source hierarchy, approval gates, prohibitions
2. **`operations/SEO-ROADMAP.md`** — current phase and priorities
3. **`operations/SEO-RISK-REGISTER.md`** — open risks that constrain what may be done
4. **`operations/DATA-ACCESS-REQUEST.md`** — what management needs to provide before baselines exist

## Structure
| Folder | Contents |
|---|---|
| `agents/` | 24 specialist definitions (01–24) — role, skills, responsibilities, inputs, outputs, KPIs, approval limits, escalation rules |
| `operations/` | Live working files — roadmap, task board, decision log, risk register, 11 data CSVs |
| `templates/` | 11 reusable workflow templates — briefs, tickets, QA, outreach, reports, experiments |

## In any Claude chat
The `mychef-seo-department` skill is installed and loads this automatically for SEO work on this project. Name a role directly if you want a specific one — "as the SEO Director…", "as the technical SEO specialist…".

## Current status
**Phase 0 — Discovery.** No Search Console, GA4, GBP, backlink or booking data has been granted, so no performance baseline exists. Figures in these files are labelled estimates or marked NO DATA. They are not results.

## Ground rules
- Traffic without relevance is not success
- Rankings without enquiries are not success
- Content without verification is not acceptable
- Links without relevance are not valuable
