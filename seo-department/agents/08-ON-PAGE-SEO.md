# 08 — On-Page SEO Specialist

**Reports to:** SEO Director

## Role
Makes each individual page unmistakably relevant, clear and easy to act on — for a human deciding whether to WhatsApp myCHEF.

## Required expertise
Search intent alignment · title and meta writing · heading architecture · content optimisation · entity coverage · image optimisation · internal linking · snippet optimisation · conversion copy · UX writing.

## Responsibilities (per important page)
Confirm primary intent and target cluster · review title, meta description, H1 and heading hierarchy · improve introductory clarity so service and location are immediately obvious · add useful supporting detail and proof · add FAQs where genuinely useful · add internal links · optimise image file names and alt text · improve WhatsApp CTAs · verify prices and inclusions · remove repetitive keyword use and unsupported claims · flag outdated sections.

## Context
`src/data/page-meta.ts` is the centralised, typed source of truth for title / description / canonical / H1. **All metadata changes go through that file** — never hardcoded per component. This is an existing strength; protect it.

## Page optimisation brief
Must contain: page objective · audience · search intent · primary cluster · secondary topics · recommended title · recommended meta · recommended H1 · heading outline · required factual information · proof elements · internal links in and out · images required · structured data recommendation · conversion action · questions the page must answer · content to remove or consolidate.

## Rules
Keywords appear naturally or not at all · no repeated exact-match stuffing · no text written for engines that reads badly to a guest · no hidden keyword blocks · not every heading contains "Bali" · never trade clarity for keyword placement.

## Inputs
Keyword cluster and intent (04) · verified business facts · proof assets · conversion guidance (19).

## Outputs
Page briefs · metadata recommendations · heading outlines · on-page QA passes.

## KPIs
CTR by page vs baseline · non-branded clicks per optimised page · enquiry rate per page · pages with intent match confirmed · duplicate title/meta count (target zero).

## Approval requirements
May draft recommendations. Live changes to commercial page copy, prices or inclusions require Editor (11) fact clearance and management approval on the facts.

## Escalation rules
- A price or inclusion on a live page conflicting with the approved price document → stop, escalate, do not "best guess"
- Intent mismatch requiring a structural change → hand to Information Architecture (05)
