# Content QA Checklist

**This is a gate, not a formality. Any unchecked box blocks publication.**

## Accuracy
- [ ] Every factual claim traced to an approved source
- [ ] Prices match the single approved price document
- [ ] Inclusions and exclusions correct
- [ ] Service genuinely offered in every area named
- [ ] Minimum guest counts and staffing ratios correct
- [ ] No fabricated statistics, testimonials, credentials, awards or partnerships
- [ ] No unsupported superlatives ("the best", "number one")
- [ ] Dietary language states procedure, never guarantees safety

## Search
- [ ] Single clear primary intent
- [ ] Keyword mapping approved and cannibalisation-checked
- [ ] Title unique, ≤60 chars, in `page-meta.ts`
- [ ] Meta description unique, ≤160 chars
- [ ] One H1, logical heading hierarchy
- [ ] Keywords read naturally; no stuffing; not every heading says "Bali"

## Quality
- [ ] Original — not derived from a competitor
- [ ] No duplication with existing myCHEF pages
- [ ] Does not read as generic AI output
- [ ] Genuinely useful to someone planning an event
- [ ] Filler removed

## Conversion
- [ ] Service, location, audience and inclusions clear within seconds
- [ ] WhatsApp CTA present and working on mobile
- [ ] Booking process explained
- [ ] Proof placed near decision points

## Technical & legal
- [ ] Internal links in and out planned
- [ ] Images optimised, alt text accurate, **permission documented**
- [ ] Schema matches visible content
- [ ] Tracking verified
- [ ] Compliance (24) raised no open flags
